# Shopping Cart Using Structures in C

## Project Description

A simple C program that uses a structure to store product details and calculate the total cost of a product in a shopping cart.

## Features

- Enter product details
- Store product information
- Enter quantity
- Calculate total cost
- Display cart details

## Technologies Used

- C
- Structures
- Arithmetic Operations

## How to Run

Compile and run the `shopping_cart.c` file using a C compiler.
